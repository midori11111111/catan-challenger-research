# Attribution and artifact scope

The evaluated game engine and native baselines are Catanatron, authored by Bryan Collazo and contributors, pinned to commit `ecf931181b9a65bb4116a2153fb78c16f1438e00`: https://github.com/bcollazo/catanatron . The upstream project declares GPL-3.0-or-later. Its license text is included as `LICENSE`; the engine is installed as a pinned dependency rather than vendored here.

The Challenger policy, frozen opening models, bridge, evaluation scripts, and report are provided as a research artifact by GitHub user `midori11111111`. The publication package uses GPL-3.0-or-later for the distributed code and included weights. The source repository and versioned release provide the publication artifact; the report is not peer-reviewed.

The project is an independent research implementation and is not affiliated with or endorsed by the publisher of CATAN. No artwork from another game site is included in the reports. Only simulated AI-game records are distributed in this artifact.

An AI coding assistant was used for implementation, code inspection, experiment orchestration, and report drafting. No language-model API is invoked to choose moves in the evaluated games. All quantitative outcome claims are generated from the stored game results.
