# Reproduce before changing

Please include the evaluated source hash, Catanatron commit, game seed, and minimal action/state example when reporting an interface or rule discrepancy. Distinguish an illegal action from a legal but strategically poor decision. The preserved Road Building fixtures illustrate the format.

For a policy proposal, retain the published snapshot as an opponent and control. Use a new source snapshot and fresh evaluation seeds, balance all six seat pairs, and decide the sample size and stopping rule before reading the confirmation results. If a board is reused across multiple futures, account for board-level clustering rather than treating all observations as independent boards.

Keep exploratory tuning, training data, and confirmation outcomes distinct. Include invalid games and adapter revisions in the record. A favorable training loss, ranking accuracy, or short pilot is not a promotion criterion. Comparing only identical self-play policies cannot by itself establish a strategic improvement.

The current artifact establishes an engine-specific external comparison. Useful follow-up work includes reconciling cached award semantics with a reference implementation, matched no-learning opening ablations, broader opponent families, and calibrated human evaluation. Do not pool a changed rules engine or adapter into the existing fixed protocol.
