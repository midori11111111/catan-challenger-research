# カタン挑戦者AI・研究公開用資料

人間の戦略知識を取り入れた本編方策と、学習済み初期配置ランキングを組み合わせたAIの外部評価です。技術レポート形式で公開できるコード・重み・評価条件・結果をまとめます。査読を受けた論文ではありません。

**評価の単位は、協力しない4人戦における「こちら2体のどちらかが勝った割合」です。互角の基準は50%です。**

## 使っているAI

gen0・gen1・gen2は本編の打ち方を共通とし、配置モデルと既存順位への混合率が異なります。gen0も既に学習済みモデルを使用しています。混合率50%は「半分の手だけ学習AIが動く」という意味ではなく、既存順位とモデル順位を同じ重みで混ぜる処理です。

モデルによる選択は、全席の1軒目と、1番手の条件付き2軒目が対象です。他の2軒目には既存のペア配置ロジックを使います。モデルの出力は候補の順位付けに使っており、各手の正確な勝率を示すものではありません。

## 今回の確認実験

最初の3,600試合計画は、2,714試合完了と1件の応答待ちタイムアウトで停止しました。加えて、伏せ札推定が「未終局なのに相手が既に10点」という仮状態を作り、AlphaBetaの探索を早期終了させる不具合が見つかりました。この旧試行は全て確認結果から除外し、再現用の反例と修正検査を保存しています。

修正版は、進行中の試合であることに整合する隠れVP枚数だけを推定します。新しい確認では、結果を見て世代を選ばず、もともとの公開標準設定gen0を固定しています。gen1/gen2は同梱しますが、この確認結果の対象には含めません。

公開標準設定gen0×2種類の相手×600試合＝1,200試合。各構成で席の6組を100回ずつ担当します。候補を絞らない深さ2のAlphaBetaとValueFunctionが相手です。双方に公開情報から推定した手札等を渡し、他人の実手札・実山札・未来の乱数を判断に利用させません。こちら2体の手札共有もありません。

試合数と判定方法を開始前に固定します。勝率の95% Wilson区間は最大約±4ポイント。2構成全体での優位の判定には、より保守的な同時Hoeffding区間（約±6.04ポイント）の下限が50%を超えることを使います。途中で都合の良い勝率になっても打ち切りません。

追加監査で、外部エンジンが道路を両方向に記録することによる初期配置手番の変換バグが判明しました。旧予備実験はそのまま別に保存し、修正後の確認実験と混ぜません。道路・港の座標、非公開情報、実ダイス乱数への副作用、初期配置の全8手、街道建設の境界ケースを検査します。

## 実行・停止・再開

英語版READMEの環境構築後、次を実行できます。新しい実験には新しい出力先を指定します。

```sh
PYTHONHASHSEED=0 .venv/bin/python confirmation.py run --out data/new-confirmation --workers 12
.venv/bin/python confirmation.py status --out data/new-confirmation
.venv/bin/python confirmation.py stop --out data/new-confirmation
PYTHONHASHSEED=0 .venv/bin/python confirmation.py resume --out data/new-confirmation --workers 12
```

停止は実行中の試合を保存してから行います。再開時にはソースの一致を確認します。接続エラーがあった試合を除外して都合よく置き換える処理はありません。

## 主張の範囲

この評価は特定の外部エンジン・相手・情報条件での結果です。世界最強、人間の上級者より強い、全ての盤面で勝てる、という主張には使いません。既存AIの評価器には、相手1人だけの生産力を考慮する制約もあります。HexMachina等との直接対戦はまだ行っていません。

公開物で再現できる範囲は、含めた重みでの判断と外部対戦評価です。人間の棋譜や全学習データ、歴史的な学習過程一式は含みません。公開サイトへの対局リンクは [こちら](https://catan-challenger-online.vercel.app/) です。
